# 商品資料來源規則

1. 價格、型號與規格以日本品牌官方網站為優先。
2. 官方網站無價格時，可使用日本大型通路的商品頁，例如 Yodobashi、Bic Camera、Alpen 或品牌授權通路；卡片必須標為「通路參考價」。
3. 舊款停售時，可使用品牌新聞稿、上市公告或可信媒體的上市資訊；卡片必須標為「上市參考價」。
4. 使用者提供的原始照片清楚拍到商品與標價時，可使用「照片標價」；不得稱為官方定價，`priceSourceUrl` 設為 `null`，並以 `priceNote` 記錄可辨識的型號或包裝。
5. 使用者上傳的原始照片可直接作為商品圖片。一張圖有多項商品時先裁切成各商品一張。
   原圖存 `images/source/<id>.<副檔名>` → 在 `images/build-manifest.json` 加一行 → 跑 `npm run build:images`，
   由腳本產生 thumb（400px）與 full（1200px）；不要手工轉檔或直接放檔到 thumb/full。
   未提供可用圖片時，才使用品牌官方圖片。所有圖片都要保留來源紀錄，
   並確認屬於個人旅遊規劃可用的合理引用範圍。
6. 搜尋摘要僅用於找到來源，不能作為唯一證據；要開啟實際商品頁確認。
7. 每筆價格都記錄查證日期。價格與庫存會變動，不承諾門市現貨。
