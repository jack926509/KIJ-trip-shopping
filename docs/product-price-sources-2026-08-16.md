# 商品價格與來源紀錄（2026-08-16）

## 修正：hasameru-sponge（掛勾式浴室海綿）品牌與價格誤植

### 問題

商品原始資料（2026-08-09 建立）將包裝標示為「山崎產業 バスボンくん はさめるスポンジ」，
價格來源取自 Yodobashi 單品頁 ¥551，購買地點列為 HANDS 博多店。

使用者於 2026-08-16 詢問「這東西應該是大創買得到吧」，經放大檢視原始商品照片
（`images/source/hasameru-sponge.jpeg`）右上角包裝夾鏈袋標籤，清楚可見 **DAISO 官方標誌**
與英文「Holdable Sponge」字樣——這款商品**本身就是 DAISO 自有品牌商品**，
不是山崎產業商品，原始資料的品牌與價格來源皆屬誤植。

### 修正後查證

| 項目 | 內容 |
|---|---|
| 商品名稱 | はさめるスポンジ（DAISO 自有品牌） |
| 官方單品頁 | <https://www.daiso-sangyo.co.jp/item/45073> |
| 含稅價格 | ¥220（税込，官方頁面直接標示） |
| JAN | 4550480772363 |
| 商品說明（官方） | 「折り目がコーナーにしっかりフィット！手が入れられるポケット付きだから、持ちやすく、今まで洗いづらかったところも簡単に！水だけでも汚れが落ちやすく、日頃のお掃除がお手楽にできちゃいます」 |
| priceKind | `official`（官方單品頁直接標價） |
| 查證日 | 2026-08-16 |

官方頁面註明「店舗によって品揃えが異なり、在庫がない場合がございます」，各分店庫存不保證，
建議以 DAISO 官方 App 查詢或現場為準。

### 購買地點

原本誤植的 `hands-hakata`（HANDS 博多店）已移除；改列既有三間 DAISO 分店
（`daiso-hakata-bus-terminal`、`daiso-amu-plaza-kokura`、`daiso-lachic-fukuoka-tenjin`），
做法與既有 `daiso-basin-cleaner-cloth` 一致。

### 教訓

商品照片本身是第一手事實來源，比先前寫入的品牌／來源紀錄更可信；
之後遇到「使用者質疑既有資料」的情境，應先重新檢視原始照片（必要時放大局部），
不要預設舊資料正確而只針對舊資料裡寫的品牌去查證。
