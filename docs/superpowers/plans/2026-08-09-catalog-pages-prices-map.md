# 實作計畫：購物目錄分頁、價格與全區門市

## 目標

將購物清單改為藥妝日用、吹風機、鞋款三個獨立頁籤，刪除結算與待確認原因；以照片可辨識的品名、型號、容量為資料界線，重新收錄可追溯的日本官方或大型連鎖通路價格，並擴充天神、博多、小倉的藥妝與鞋店地圖。

## 實作順序

1. 盤點歷史 PR、既有研究與所有商品照片，建立每項商品的辨識、價格、來源與門市資料規格。
2. 調整 `assets/products.js` 與資料驗證：只有可追溯價格才顯示售價；無法確認者只顯示「價格待確認」，不顯示原因文字。
3. 改寫 `index.html` 為三頁籤目錄，移除結算和所有結算程式碼，並在吹風機／鞋款卡片顯示既有研究摘要與直接來源。
4. 擴充 `map.html` 的店家資料與篩選，僅加入具有官方門市頁或官方樓層導覽可證實的天神、博多、小倉藥妝與鞋店。
5. 更新商品管理 Skill 的說明與範本，讓新增商品必填照片辨識、價格種類、直接來源和門市證據。
6. 執行資料驗證、桌機與手機瀏覽器驗收、地圖篩選／跨頁定位驗收，提交並推送 `main` 觸發 Vercel 部署；核對正式站。

## 驗收條件

- 僅有三個清單頁籤，沒有結算導覽或結算內容。
- 卡片不出現「價格待確認原因」；可確認價格皆有可開啟的直接來源。
- 吹風機兩款呈現規格、旅遊選購建議與評價界線；On、HOKA 各五款都呈現現行官方價格、選購定位與來源。
- 地圖可篩選天神、博多、小倉的藥妝與鞋店，店家卡與商品卡互相定位。
- `npm run validate:data`、資料來源連結檢查、1280 px／390 px 畫面、正式 Vercel 頁面皆通過。
