# 博多・天神購物地圖設計規格

日期：2026-08-02（Asia/Taipei）  
狀態：使用者已確認設計方向，等待書面規格複核

## 目標

在既有北九州之旅購物清單旁新增一個獨立的「博多・天神購物地圖」頁面，將購物清單中反覆提及的店家整理成可實際導航的地圖。地圖不追求列出每一家分店，而是每個品牌選擇博多或天神最順路的 1–2 間分店，降低標記密度並方便現場決策。

同時調整 HOKA Fukuoka Tenjin 的提醒文字：保留直營店身分、地址、電話與 11:00–20:00 營業時間，移除「非博多／小倉」說明。

## 範圍

### 包含

- 新增獨立靜態頁面 `map.html`。
- 在 `index.html` 提供前往地圖頁的清楚入口。
- 在 `map.html` 提供返回購物清單的入口。
- 使用 OpenStreetMap 底圖及 Leaflet 互動功能。
- 依類別標示鞋款、藥妝、生活雜貨與超市。
- 每間店家顯示名稱、品牌、區域、地址、營業時間、適合購買的品項與 Google Maps 導航連結。
- 依博多／天神與店家類別篩選店家。
- 桌面與手機響應式版面。
- 地圖載入失敗時仍保留完整店家清單與導航功能。

### 不包含

- 不建立會員、後端、資料庫或即時庫存系統。
- 不建立自訂 Google My Maps。
- 不保證店家當日庫存、促銷或臨時營業異動。
- 不收錄小倉地區店家。
- 不把一般經銷商標示為品牌直營店或專賣店。
- 不修改商品價格、勾選狀態或購物清單計算功能。

## 店家資料原則

地圖資料必須優先使用品牌官方門市頁、商場官方店鋪頁或連鎖店官方搜尋結果。每個購物清單內出現的品牌原則上收錄 1 間；若博多與天神各有明顯順路且實用的分店，最多收錄 2 間。

候選品牌如下：

- 鞋款：HOKA、Alpen／SPORTS DEPO、On 授權通路。
- 藥妝：唐吉訶德、松本清、SUNDRUG、大國藥妝。
- 生活雜貨：3COINS、DAISO。
- 超市：AEON、MaxValu、YouMe 中選擇最符合博多／天神動線者。

若某品牌在博多或天神沒有適合且可由官方確認的分店，地圖不為了湊數而加入較遠店家。營業時間與店名於實作查核日記錄，頁面同時顯示「出發前再次確認」提醒。

## 資訊架構

### 主購物清單

`index.html` 的頁首操作區新增「博多・天神地圖」連結。連結採一般頁面導覽，不使用新瀏覽器視窗，讓手機返回操作保持直覺。

### 地圖頁

`map.html` 由下列區塊組成：

1. 頁首：頁面名稱、簡短說明、返回購物清單。
2. 篩選列：全部、博多、天神，以及鞋款、藥妝、生活雜貨、超市。
3. 互動地圖：初始視野同時涵蓋博多站、Canal City 與天神商圈。
4. 店家清單：與地圖標記同步篩選；點擊卡片時地圖聚焦對應標記。
5. 使用提醒：營業時間與庫存需在出發前再次確認。

## 視覺與互動

- 延續既有網站的米白背景、墨綠主色、圓角卡片與細緻陰影。
- 標記依類別分色：鞋款用藍色、藥妝用綠色、生活雜貨用金色、超市用橘色。
- 桌面版採地圖與店家清單左右並排；地圖保持在可視區域內，清單可向下瀏覽。
- 手機版改為地圖在上、店家清單在下，篩選按鈕可橫向滑動。
- 點擊地圖標記顯示簡短資訊與「查看店家卡片」。
- 點擊店家卡片可聚焦標記；點擊導航按鈕則開啟 Google Maps 搜尋／導航頁。
- HOKA Fukuoka Tenjin 明確標示為直營店並顯示 11:00–20:00。

## 技術設計

- 維持無建置流程的靜態 HTML、CSS、JavaScript 架構。
- 新增 `map.html`，避免讓既有單頁 `index.html` 繼續膨脹。
- Leaflet 的 CSS 與 JavaScript 使用固定版本 CDN。
- OpenStreetMap 作為圖磚來源，頁面保留必要的圖資署名。
- 店家資料集中為單一 JavaScript 陣列；地圖標記與店家卡片從同一份資料渲染，避免地址、營業時間或分類不一致。
- 地址連結使用 Google Maps 搜尋 URL，避免依賴特定裝置的地圖 App。
- 不使用 API key，不新增秘密或環境變數。

## 資料流

1. 頁面載入店家資料陣列。
2. 建立 OpenStreetMap 與各店家標記。
3. 由同一份資料產生店家卡片。
4. 使用者選擇區域或類別後，重新計算符合條件的資料集合。
5. 地圖只顯示符合條件的標記，清單只顯示相同集合的卡片。
6. 點擊卡片時，以店家識別碼找到對應標記並聚焦。

## 錯誤與降級處理

- Leaflet 或地圖圖磚載入失敗時，地圖區顯示「地圖暫時無法載入」，但店家卡片、地址與 Google Maps 導航仍正常使用。
- 店家沒有可確認營業時間時，顯示「請於出發前向官方確認」，不自行估算。
- 篩選後沒有店家時，顯示清楚的空狀態並保留重設篩選按鈕。
- 外部連結使用新視窗並加上安全的 `rel` 屬性。

## 驗收標準

- 主頁可以進入 `map.html`，地圖頁可以返回主頁。
- 頁面可在桌面與手機尺寸正常顯示，沒有橫向溢位。
- 初始地圖視野涵蓋博多站、Canal City 與天神。
- 所有店家標記與卡片一一對應。
- 區域與類別篩選會同步更新標記與卡片。
- 點擊店家卡片會聚焦正確標記。
- 每個導航連結會開啟對應店家的 Google Maps 頁面。
- HOKA Fukuoka Tenjin 顯示 11:00–20:00，且不出現「非博多／小倉」文字。
- 關閉或阻擋地圖外部資源時，店家清單與導航連結仍可使用。
- HTML／JavaScript 檢查、差異檢查與實際瀏覽器驗證皆通過。
