# 地圖頁底部導覽一致化設計

## 背景

桌機版清單頁與行程頁的底部導覽會顯示成螢幕下方置中的膠囊，但地圖頁仍橫跨整個視窗。三個頁面使用相同的 `.kij-bottombar` HTML，差異來自桌機 CSS 被 `body.kij` 限定，而地圖頁的 `<body>` 沒有這個 class。

## 已確認方向

採用共用樣式方案：將 `@media (min-width: 821px)` 內的底部導覽規則直接套用到所有 `.kij-bottombar`，不在地圖頁複製 CSS，也不替地圖頁加入可能影響其他版面的 `kij` class。

## 介面行為

- 桌機寬度 821px 以上：清單、行程、地圖皆使用相同的置中膠囊導覽，寬度上限 460px、離視窗底部 18px。
- 目前頁面的項目維持淡綠底與深綠文字；地圖頁仍由「地圖」項目標示 `aria-current="page"`。
- 手機寬度 820px 以下：保留既有滿寬底部導覽，不改變地圖抽屜與地圖操作方式。
- 既有 44px 最小觸控高度、鍵盤焦點樣式與三個導覽連結全部保留。

## 實作範圍

- 修改 `assets/kij.css` 的桌機導覽選擇器與說明註解。
- 修改 `scripts/test-list-ui.mjs`，防止桌機膠囊樣式再次被限制於清單／行程頁。
- 不修改地圖資料、商品資料、行程資料或 JavaScript 互動。

## 驗收標準

- `npm test` 與 `npm run validate:data` 通過。
- 1280px 桌機寬度下，三頁底部導覽的寬度、位置、排列與選取樣式一致。
- 390px 手機寬度下，三頁仍使用滿寬導覽且沒有水平溢出。
- 地圖頁可正常顯示與操作，瀏覽器 console 沒有錯誤。
